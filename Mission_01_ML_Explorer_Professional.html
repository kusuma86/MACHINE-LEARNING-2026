3. Before You Start

📖 Reading Goal

Tidak perlu menghafalkan semua istilah. Fokus pada ide dasar dan hubungan antar-konsep.

3.1 Artificial Intelligence

Artificial Intelligence (AI) adalah bidang yang mempelajari bagaimana membuat komputer atau mesin mampu melakukan tugas yang biasanya membutuhkan kecerdasan manusia.

Contohnya:

  • mengenali wajah;
  • memahami suara;
  • menerjemahkan bahasa;
  • mendeteksi kerusakan mesin;
  • memberi rekomendasi;
  • membantu pengambilan keputusan.

Namun, tidak semua AI menggunakan Machine Learning.

Sebuah sistem dapat terlihat cerdas karena mengikuti aturan yang telah dibuat manusia.

IF temperature > 30 °C
THEN fan = ON
ELSE fan = OFF

Sistem tersebut dapat mengambil keputusan, tetapi tidak belajar dari data.

3.2 Machine Learning

Machine Learning (ML) adalah bagian dari AI yang memungkinkan komputer mempelajari pola dari data sehingga dapat membuat prediksi atau keputusan tanpa setiap aturan ditulis secara eksplisit.

Rule-Based

IF vibration > 1.5
AND temperature > 60
THEN machine_condition = FAULT

Aturan dibuat oleh manusia.

Machine Learning

Kita memberikan contoh kepada komputer:

Temperature Vibration Condition
32 0.20 Normal
35 0.25 Normal
61 1.40 Fault
70 1.80 Fault

Komputer kemudian mempelajari pola hubungan antara input dan kondisi mesin.

3.3 Deep Learning

Deep Learning (DL) adalah bagian dari Machine Learning yang menggunakan jaringan saraf tiruan dengan banyak lapisan.

Artificial Intelligence
        ↓
Machine Learning
        ↓
Deep Learning

💡 Remember

Kita tidak akan langsung mengejar model yang kompleks.
Kita mulai dari memahami masalah, data, dan alur pembelajaran mesin.

4. How Does a Machine Learn?

DATA
  ↓
LEARNING ALGORITHM
  ↓
MODEL
  ↓
NEW DATA
  ↓
PREDICTION

Contoh:

Temperature + Vibration + Current
                ↓
        Machine Learning
                ↓
          Normal / Fault

Model tidak “berpikir” seperti manusia. Model mencari pola matematis dari data yang diberikan.

5. Essential ML Vocabulary

Istilah Arti Sederhana
Dataset Kumpulan data untuk proses Machine Learning
Sample Satu contoh atau satu baris data
Feature Variabel masukan yang digunakan model
Label / Target Jawaban atau keluaran yang dipelajari
Training Proses model belajar dari data
Model Hasil proses pembelajaran
Inference Menggunakan model yang sudah dilatih pada data baru
Prediction Keluaran yang dihasilkan model

Contoh

Temperature Vibration Condition
35 0.25 Normal
65 1.40 Fault 
Features : Temperature, Vibration
Label    : Condition

6. Supervised and Unsupervised Learning

6.1 Supervised Learning

Pada supervised learning, data training memiliki target atau label.

Regression

Output berupa nilai kontinu.

Temperature + Humidity
        ↓
       Model
        ↓
Predicted Power = 125.4 W

Classification

Output berupa kategori.

Temperature + Vibration
        ↓
       Model
        ↓
       FAULT

6.2 Unsupervised Learning

Pada unsupervised learning, data tidak memiliki label yang sudah diberikan.

Model mencoba mencari pola atau kelompok.

Sensor Data
    ↓
Clustering
    ↓
Group A / Group B / Group C

9. Guided Exploration — Your First ML Model

Pada eksperimen ini kita menggunakan Python dan scikit-learn.

Jangan hanya menyalin kode. Baca setiap bagian dan pahami apa yang sedang dilakukan.

9.1 Import Library

import numpy as np
from sklearn.neighbors import KNeighborsClassifier

9.2 Prepare the Data

X = np.array([
    [31, 0.20],
    [35, 0.30],
    [38, 0.40],
    [60, 1.20],
    [65, 1.50],
    [72, 1.90]
])

y = np.array([
    "Normal",
    "Normal",
    "Normal",
    "Fault",
    "Fault",
    "Fault"
])
X = features
y = labels

9.3 Create the Model

model = KNeighborsClassifier(n_neighbors=3)

9.4 Train the Model

model.fit(X, y)

9.5 Perform Inference

new_data = np.array([
    [62, 1.40]
])

prediction = model.predict(new_data)

print("Prediction:", prediction[0])

Bandingkan hasil komputer dengan prediksi manual Anda.
