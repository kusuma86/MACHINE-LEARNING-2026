# Machine Learning 2026

Repositori ini disusun sebagai media pembelajaran untuk mata kuliah **Machine Learning 2026** yang ditujukan bagi mahasiswa **Semester V Program Studi Teknik Otomasi, Jurusan Teknik Elektro, Politeknik Negeri Bali**.

Mata kuliah ini dirancang untuk memberikan pemahaman yang bertahap mengenai **Machine Learning**, mulai dari pengenalan data, prapemrosesan, pemodelan, evaluasi model, neural network, hingga implementasi model pada perangkat edge seperti **Raspberry Pi** dan **mikrokontroler**. Pendekatan pembelajaran diarahkan tidak hanya pada pemahaman teori, tetapi juga pada kemampuan mahasiswa dalam membangun, menguji, mengevaluasi, dan mengimplementasikan sistem Machine Learning dalam konteks teknik dan otomasi.

Repositori ini akan digunakan sebagai tempat untuk menyimpan dan membagikan berbagai sumber pembelajaran yang digunakan selama perkuliahan, termasuk:

- materi pembelajaran;
- kumpulan skrip Python penting;
- contoh program;
- dataset latihan;
- latihan pemrograman;
- notebook Jupyter;
- contoh implementasi Machine Learning;
- latihan evaluasi model;
- eksperimen neural network;
- deployment model ke perangkat edge;
- materi pendukung praktikum;
- serta berbagai contoh dan latihan tambahan yang relevan dengan perkuliahan.

Materi akan dikembangkan secara bertahap mengikuti alur pembelajaran selama satu semester. Secara umum, topik yang dibahas meliputi:

1. **Fundamentals of Machine Learning**
2. **Data Exploration and Understanding**
3. **Data Preprocessing**
4. **Regression for Prediction**
5. **Classification for Decision-Making**
6. **Model Performance Evaluation**
7. **Model Performance Improvement**
8. **Midterm Integrated Challenge**
9. **Fundamentals of Neural Networks**
10. **Neural Network Training**
11. **Model Deployment on Raspberry Pi**
12. **Sensor Integration and Real-Time Inference**
13. **TinyML on Microcontrollers**
14. **Prediction and Actuator Integration**
15. **End-to-End Machine Learning System Integration**
16. **Final Demonstration and Technical Defense**

Pembelajaran akan banyak menggunakan **Python**, **Jupyter Notebook**, serta beberapa library Machine Learning seperti **NumPy**, **pandas**, **Matplotlib**, dan **scikit-learn**. Pada tahap selanjutnya, mahasiswa juga akan diperkenalkan pada implementasi Machine Learning di lingkungan **Raspberry Pi**, **ESP32**, dan perangkat embedded lainnya.

Salah satu tujuan utama dari mata kuliah ini adalah agar mahasiswa tidak berhenti pada tahap membuat model dengan nilai akurasi tertentu. Mahasiswa diharapkan memahami keseluruhan alur pengembangan sistem Machine Learning, mulai dari:
