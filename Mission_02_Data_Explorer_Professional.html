1. Mission Brief

Pada Mission 01, Anda telah mengenal alur dasar:

Problem → Data → Training → Model → Inference → Prediction

Sekarang kita berhenti sejenak pada bagian yang paling sering diremehkan:

DATA

Sebelum memilih algoritma, sebelum training, bahkan sebelum membahas accuracy, seorang engineer harus memahami data yang akan digunakan.

Pada mission ini Anda akan belajar membaca dataset seperti seorang investigator:

  • apa yang diukur;
  • mana feature dan mana target;
  • berapa banyak sample;
  • bagaimana rentang nilainya;
  • apakah ada pola;
  • apakah ada nilai yang mencurigakan;
  • dan apakah visualisasi mendukung dugaan Anda.

Good models begin with understood data.

2. Learning Outcomes

Setelah menyelesaikan mission ini, Anda diharapkan mampu:

  1. menjelaskan struktur dasar sebuah dataset;
  2. membedakan sample, feature, dan target;
  3. mengenali tipe data numerik dan kategorikal;
  4. menghitung statistik dasar: minimum, maksimum, mean, dan median;
  5. menggunakan pandas untuk membaca dan mengeksplorasi dataset;
  6. membuat visualisasi sederhana menggunakan matplotlib;

3. Before You Start

📖 Reading Goal

Saat membaca bagian ini, jangan fokus menghafal fungsi Python.
Fokus pada pertanyaan: “Apa yang ingin saya ketahui dari data ini?”

3.1 What Is a Dataset?

Dataset adalah kumpulan data yang digunakan untuk analisis atau pembelajaran mesin.

Contoh:

Temperature Humidity Light Condition
27 72 450 Normal
29 76 420 Normal
34 82 320 Warning
38 88 250 Critical

Setiap baris adalah satu sample.

Setiap kolom adalah satu variabel.

Pada contoh tersebut:

Features:
- Temperature
- Humidity
- Light

Target:
- Condition

4. Samples, Features, and Targets

4.1 Sample

Satu sample adalah satu pengamatan.

Misalnya:

[34, 82, 320, "Warning"]

berarti satu kondisi sistem pada satu waktu tertentu.

4.2 Feature

Feature adalah informasi input yang digunakan untuk memahami atau memprediksi target.

Contoh:

  • temperature;
  • humidity;
  • vibration;
  • current;
  • light intensity;
  • water level.

4.3 Target

Target adalah nilai yang ingin diprediksi atau dijelaskan.

Contoh:

Condition = Normal / Warning / Critical

atau:

Power = 125.4 W

5. Numerical and Categorical Data

Secara sederhana, data dapat dibagi menjadi:

Numerical

Berupa angka.

Contoh:

Temperature = 32.5
Current = 3.8
Humidity = 75

Categorical

Berupa kategori atau kelas.

Contoh:

Condition = Normal
Mode = Auto
Machine = Motor_A

💡 Remember

Angka tidak selalu berarti “lebih besar lebih baik”, dan kategori tidak selalu bisa langsung diproses sebagai angka.

Memahami makna fisik setiap feature sangat penting.

6. Why Statistics Matter

Sebelum menggambar grafik, kita dapat melihat ringkasan statistik.

Beberapa statistik dasar:

Statistik Arti
Minimum Nilai terkecil
Maximum Nilai terbesar
Mean Nilai rata-rata
Median Nilai tengah setelah data diurutkan
Count Jumlah sample

Misalnya temperature:

28, 29, 30, 31, 70

Mean dapat meningkat cukup besar karena angka 70.

Median lebih tahan terhadap nilai ekstrem.

Ini akan menjadi penting saat kita masuk ke outlier pada mission berikutnya.

8. Guided Exploration — Reading Data with Pandas

Kita akan menggunakan pandas.

8.1 Import Library

import pandas as pd
import matplotlib.pyplot as plt

8.2 Create a Small Dataset

data = {
    "temperature": [31, 33, 36, 49, 55, 62, 68, 72],
    "humidity":    [70, 72, 75, 78, 80, 84, 87, 89],
    "vibration":   [0.20, 0.25, 0.35, 0.70, 1.00, 1.40, 1.70, 1.95],
    "condition":   ["Normal", "Normal", "Normal",
                    "Warning", "Warning",
                    "Fault", "Fault", "Fault"]
}

df = pd.DataFrame(data)

8.3 View the Data

print(df)

Kemudian:

print(df.head())

Pertanyaan

Apa perbedaan print(df) dan df.head()?

9. Inspect the Structure

Gunakan:

print(df.shape)

Jika hasilnya:

(8, 4)

artinya dataset memiliki:

8 rows
4 columns

Coba juga:

print(df.columns)

dan:

print(df.dtypes)

Catat hasilnya

Jumlah sample: ___________________

Jumlah kolom: ___________________

Kolom numerik: ___________________

Kolom kategorikal: _______________

10. Basic Statistics

Gunakan:

print(df.describe())

Perhatikan nilai:

  • count;
  • mean;
  • min;
  • max;
  • median (50%).

Lengkapi tabel berikut.

Feature Minimum Maximum Mean Median
Temperature
Humidity
Vibration

Diskusikan

Feature mana yang memiliki rentang terbesar?

Apakah rentang besar selalu berarti feature tersebut paling penting?

11. Count the Classes

Gunakan:

print(df["condition"].value_counts())

Catat jumlah masing-masing kelas.

Condition Count
Normal
Warning
Fault

💡 Key Insight

Jumlah sample pada setiap kelas dapat memengaruhi proses training.
Dataset dengan satu kelas yang jauh lebih banyak dari kelas lain disebut imbalanced dataset.

Kita akan membahas dampaknya lebih jauh pada mission berikutnya.

12. Visualise the Data

Angka sering kali lebih mudah dipahami ketika divisualisasikan.

12.1 Temperature

plt.scatter(range(len(df)), df["temperature"])
plt.xlabel("Sample")
plt.ylabel("Temperature")
plt.title("Temperature per Sample")
plt.show()

12.2 Vibration

plt.scatter(range(len(df)), df["vibration"])
plt.xlabel("Sample")
plt.ylabel("Vibration")
plt.title("Vibration per Sample")
plt.show()

13. Compare Two Features

Sekarang buat hubungan antara temperature dan vibration.

plt.scatter(df["temperature"], df["vibration"])
plt.xlabel("Temperature")
plt.ylabel("Vibration")
plt.title("Temperature vs Vibration")
plt.show()

Pertanyaan

  1. Apakah terlihat hubungan antara temperature dan vibration?
  2. Apakah vibration cenderung meningkat saat temperature meningkat?
  3. Apakah grafik ini membuktikan hubungan sebab-akibat?

Catatan: Korelasi atau pola pada grafik tidak otomatis membuktikan bahwa satu variabel menyebabkan variabel lain.
